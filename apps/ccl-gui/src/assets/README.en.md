# GUI artwork

`default-wallpaper.webp` is original static scenery generated with OpenAI image_gen on 2026-10-26 for CCL and converted to WebP for distribution. It was generated as an app asset, not extracted from Minecraft or the earlier UI concept screenshot. It contains no third-party logos or characters. It does not imply Mojang endorsement. CCL distributes this project asset under the repository license.

Prompt: a serene original voxel alpine lake with distant block mountains, conifers and a grassy left foreground, soft daylight, a quiet darker lower-right region for controls; no text, UI, characters, logos or frame.

The local concept screenshots under `.local` are planning records and are not packaged.
