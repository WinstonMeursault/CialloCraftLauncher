# CialloCraftLauncher

一个使用 Rust 编写的自由、开源、跨平台 Minecraft 启动器。

## 项目状态

项目处于早期开发阶段。当前 `ccl` 命令行提供只读环境检查 `doctor`，以及创建游戏目录的 `init`。安装、下载和身份验证功能尚未实现。
